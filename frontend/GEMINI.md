# Frontend Guidelines & Conventions

## Strict Rules
- **ZERO EMOJIS**: Strictly forbidden across all UI, text, map overlays, popups, and components. Use `lucide-react` SVG icons exclusively.
- **Ultra-Clean Professional UI**: Modern GIS & Defense Intelligence dashboard aesthetic.
- **Typography**: Geist Sans + Geist Mono for all telemetry readouts (coordinates, elevation, tides, timestamps).
- **Theme**: Premium slate/zinc dark aesthetic with refined hairline borders, luminous semantic status pills, and glassmorphic micro-HUDs.
