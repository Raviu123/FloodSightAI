# Design & Frontend Code Rules

1. **NO EMOJIS**: Do not use unicode emojis anywhere in this project. Use `lucide-react` SVG icons or styled text badges.
2. **Professional Command Center Aesthetic**: High precision, clean borders, slate dark themes, crisp typography, and high-density telemetry data layout.
3. **No AI-looking placeholder cliches**: Avoid generic gradient blur blobs, playful text, and low-contrast elements.
